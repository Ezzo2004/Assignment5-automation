# Assignment5-automation
This project uses a Selenium-based web scraper to collect technology deals from the eBay Global Deals page. The scraper extracts product titles, prices, original prices, shipping information, timestamps, and product URLs. The data is then cleaned by removing currency symbols, converting prices to numeric values, handling missing values, and calculating discount metrics. Exploratory data analysis was performed to examine price distributions, discounts, shipping options, and keyword frequencies in product titles.

During development, several technical challenges were encountered when working with GitHub and automation. Managing commits and updates required handling situations where there were no changes to push, which could cause workflow errors. Synchronizing local and remote repositories also required careful use of pulling and pushing changes to avoid conflicts. Additionally, configuring the GitHub Actions workflow to run the scraper, cleaning script, and analysis notebook automatically required debugging dependency installations and ensuring all steps executed correctly.
